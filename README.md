# .github

The profile page of the [Callout-Studio](https://github.com/Callout-Studio) organization.

| File | What it is |
| :-- | :-- |
| [`profile/README.md`](profile/README.md) | The text of the page. Edit it here. |
| [`profile/banner.svg`](profile/banner.svg) | The banner at its top. It is generated: don't edit it here. |

The banner's source is in the plugin repository, in `assets/github-org/` of [Callout-Studio/obsidian](https://github.com/Callout-Studio/obsidian). To change it, edit the generator there, run it, and copy the new `banner.svg` over `profile/banner.svg`.
